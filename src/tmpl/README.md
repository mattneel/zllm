# tmpl

Not started; planned for M4.

Handlebars-subset renderer written in Zig: `{{x}}`, `{{#if}}`/`{{else}}`, `{{#each}}`, `{{#range a b}}`, partials, and the fixed helper set (add, mul, ceil_div, vec_type, enable). No arbitrary code.

See the [spec](../../docs/src/spec.md) and [architecture](../../docs/src/architecture.md).
